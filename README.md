# 🎲 Python Dice Roller

A simple and interactive **Dice Roller built with Python**. The program allows users to choose the number of dice they want to roll, generates random values from 1 to 6, displays each dice using ASCII art, and calculates the total score.

## ✨ Features

* 🎲 Roll any number of dice
* 🔢 Generates random values between 1 and 6
* 🖥️ Displays dice using ASCII art
* ➕ Calculates the total of all rolled dice
* 🐍 Beginner-friendly Python project
* 💻 Runs directly in the terminal

## 🛠️ Technologies Used

* **Python 3**
* `random` module
* ASCII Art

## 🎮 How It Works

When the program starts, it asks:

```text
How many dice?:
```

Enter the number of dice you want to roll.

For example:

```text
How many dice?: 3
```

The program randomly generates a value between **1 and 6** for each die and displays the corresponding dice artwork.
